Comment cet annuaire est tenu.

Chaque jour ouvré, un robot parcourt les forges logicielles, les portails de données ouvertes et les dépôts de modèles. Il ne retient que ce qui porte une licence réellement ouverte et propose ses trouvailles aux relecteurs de l'association. Rien n'est publié ici sans validation humaine. Le code du radar est dans le dépôt du site. Un projet manque ? Signalez-le.
