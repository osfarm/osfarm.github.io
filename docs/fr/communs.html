Comment cet annuaire est tenu

Le radar

Chaque jour ouvré, un robot parcourt les forges logicielles, les portails de données ouvertes et les dépôts de modèles. Il ne retient que ce qui porte une licence réellement ouverte et propose ses trouvailles aux relecteurs de l'association. Rien n'est publié sans validation humaine. Le code du radar est dans le dépôt du site.

Ce que nous retenons

Des projets en phase de production, dont le code source ou les données sont publiés. Si vous remarquez l'utilisation de votre logo sans votre accord, ou si vous souhaitez retirer un projet, faites-le nous savoir.

Ajouter un projet

Ce site est open source : une personne de la communauté relira votre proposition.

  1. Ouvrez la liste des projets de la communauté, _data/radar/communaute.yml.
  2. Cliquez sur l'icône crayon (« Edit ») en haut à droite.
  3. Ajoutez une fiche pour votre projet ; l'en-tête du fichier décrit chaque champ.
  4. Cliquez sur « Propose changes » en bas de la page.
  5. Décrivez votre contribution, puis cliquez sur « Create pull request ».
