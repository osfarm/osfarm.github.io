{%- comment -%} Le prix d'un niveau d'accompagnement pour un public donné. Usage : {% include adhesion-prix.html niveau=n public="apm" lang="fr" %} `public` vaut « public » ou l'id d'une formule de _data/adhesion.yml. Sans `prix`, le niveau est sur devis.
