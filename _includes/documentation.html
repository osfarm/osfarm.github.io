Comment cette documentation est tenue

Chaque lien est ouvert et daté avant publication, et l'année indiquée est celle du document, non celle de sa page web. Les prépublications et les portails le disent sur leur fiche. Les résumés sont rédigés par l'association ; ils ne remplacent pas la lecture du texte.

Une référence à proposer, une erreur à corriger ? Écrivez-nous, ou ouvrez une pull request sur _data/publications.yml.

{%- else %}

How this list is kept

Every link is opened and dated before publication, and the year shown is the document's, not its web page's. Preprints and portals say so on their card. Summaries are written by the association; they are no substitute for reading the text.

A reference to suggest, a mistake to fix? Write to us, or open a pull request on _data/publications.yml.
